# بوت إحصائيات الإداريين

بوت ديسكورد يتابع نشاط الأعضاء اللي يحملون رتبة الإداريين، ويحسب لهم سكور، ويعرض إحصائياتهم عن طريق أمر `/adminstats`.

## المميزات
- تتبع عدد الرسائل
- تتبع ساعات الحضور الصوتي العام
- تتبع ساعات روم الدعم الصوتي (Support VC) بشكل منفصل
- تتبع الإجراءات الإدارية (كيك / بان / تايم اوت) تلقائياً عن طريق الـ Audit Log
- إضافة فعاليات يدوياً بأمر `/addevent`
- سكور محسوب تلقائياً حسب أوزان قابلة للتعديل في `config.js`
- أمر `/adminstats` يعرض:
  - إحصائيات إداري واحد (لو حددت `member`)
  - ليدربورد لكل الإداريين مرتبين حسب السكور (لو ما حددت أحد)

## خطوات التشغيل

### 1. تثبيت المتطلبات
```
npm install
```

### 2. إعداد متغيرات البيئة
انسخ `.env.example` إلى ملف اسمه `.env` وعبّي فيه:
- `DISCORD_TOKEN`: توكن البوت من https://discord.com/developers/applications
- `CLIENT_ID`: آيدي التطبيق (Application ID)
- `GUILD_ID`: آيدي السيرفر اللي بيشتغل فيه البوت

### 3. تفعيل الصلاحيات المطلوبة (Intents)
من صفحة تطبيق البوت في Discord Developer Portal، فعّل:
- SERVER MEMBERS INTENT
- MESSAGE CONTENT INTENT

### 4. تعديل `config.js`
- تأكد إن `ADMIN_ROLE_ID` مضبوط على الرتبة الصح (موجود مسبقاً: `1514988741310156881`)
- عدّل `SUPPORT_VC_CHANNEL_ID` لآيدي روم الدعم الصوتي عندك
- عدّل `SCORE_WEIGHTS` حسب كيف تبي توزع النقاط

### 5. رفع أوامر السلاش للسيرفر
```
npm run deploy
```

### 6. تشغيل البوت
```
npm start
```

## الأوامر
| الأمر | الوصف | الصلاحية |
|---|---|---|
| `/adminstats [member]` | عرض إحصائيات إداري واحد أو ليدربورد الكل | الجميع |
| `/addevent member count` | إضافة فعالية لإداري | Manage Server |
| `/resetstats [member]` | تصفير إحصائيات إداري أو الكل | Administrator |

## ملاحظات
- البيانات تتخزن محلياً في ملف `data.sqlite` بجذر المشروع، يعني ما تنمسح لو سويت ريستارت للبوت.
- لازم تشغّل البوت على سيرفر VPS أو استضافة تدعم Node.js عشان يفضل شغال 24/7 (مثل Railway, Render, أو VPS خاص).
